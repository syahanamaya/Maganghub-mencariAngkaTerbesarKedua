Mencari Angka Terbesar Kedua dengan JavaScript

Deskripsi
Program sederhana menggunakan JavaScript untuk mencari angka terbesar kedua yang berbeda dalam sebuah array tanpa menggunakan metode `sort()`.

Teknologi
- HTML5
- JavaScript

Cara Menjalankan Program

1. Clone atau download repository ini.
2. Buka folder project di Visual Studio Code.
3. Cari file `index.html`.
4. Klik kanan pada file `index.html`, kemudian pilih Open with Live Server.

   Alternatif: buka file `index.html` langsung menggunakan browser seperti Google Chrome.

5. Setelah halaman terbuka, tekan tombol `F12` pada keyboard.
6. Pilih tab Console pada Developer Tools.
7. Hasil pencarian angka terbesar kedua akan ditampilkan di Console.
